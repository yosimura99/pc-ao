# PC Ảo

Giả lập máy tính kiểu Windows 11 siêu nhẹ chạy trên web (HTML/CSS/JS thuần, không build, không thư viện). Có thể cài như PWA trên iPhone.

**Live:** https://yosimura99.github.io/pc-ao/ · **Bot API:** [bot.html](https://yosimura99.github.io/pc-ao/bot.html) · [llms.txt](https://yosimura99.github.io/pc-ao/llms.txt)

Ứng dụng: Quản lý tệp, Notepad, Terminal, Máy tính, Trình duyệt, Cài đặt, Gợi ý trả lời.

Bot điều khiển bằng link, ví dụ: `?skipboot=1&run=notepad&cmd=mkdir%20test;ls` — kết quả nằm trong `#bot-output`.

«Gợi ý trả lời» chạy offline bằng luật + mẫu câu; KHÔNG kết nối Tinder hay dịch vụ hẹn hò/nhắn tin nào và KHÔNG tự gửi gì.
