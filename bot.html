PC Ảo – điều khiển bằng link / drive it with a link

PC Ảo là giả lập máy tính kiểu Windows 11 siêu nhẹ (HTML/CSS/JS thuần, không thư viện). Bot hoặc công cụ tự động chỉ cần mở một đường link có tham số là máy tự chạy lệnh và ghi kết quả vào DOM.
PC Ảo is a super-light Windows-11-style PC simulator (plain HTML/CSS/JS, no libraries). A bot only has to open a link with parameters; the actions run after boot and results are mirrored into the DOM.

Trang chính / Main app: https://yosimura99.github.io/pc-ao/ · Tóm tắt cho LLM / LLM summary: llms.txt

Ứng dụng «Gợi ý trả lời» KHÔNG kết nối với Tinder hay bất kỳ dịch vụ hẹn hò hoặc nhắn tin nào khác, và KHÔNG tự động gửi bất cứ thứ gì. Nó chỉ chạy offline trong trình duyệt bằng luật và mẫu câu có sẵn; bạn tự sao chép và tự gửi.
The “Gợi ý trả lời” (reply suggester) app does NOT connect to Tinder or any other dating or messaging service, and does NOT send anything automatically. It runs offline in your browser using built-in rules and templates; you copy and send replies yourself.

Tham số URL / URL parameters

Dùng được cả ?a=b lẫn #a=b (hash ghi đè query). Nhớ URL-encode giá trị. Both query and hash work (hash overrides). URL-encode values.

Tham số / ParamÝ nghĩa / Meaning
skipboot=1Bỏ qua màn khởi động và màn khóa. Skip boot + lock screen instantly. (With any action param the lock screen is auto-dismissed after a ~0.75 s boot anyway.)
run=id1,id2Mở ứng dụng. Open apps. IDs: explorer, notepad, terminal, calc, browser, settings, reply (alias: files, note, cmd, shell, calculator, web, caidat, goiy…)
cmd=lệnh1;lệnh2Chạy lệnh Terminal, ngăn bằng ;. Kết quả vào #bot-output. Run terminal commands separated by ; (max 50). Output goes to #bot-output. Lệnh: help, ls, cd, pwd, mkdir, touch, cat, echo (> >>), rm [-r], mv, open, apps, theme, wallpaper, date, whoami, history, clear, neofetch, reply
file=/đường/dẫn.txt&text=...Ghi tệp (thư mục cha phải tồn tại) rồi mở bằng Notepad. Chỉ file: mở tệp/thư mục có sẵn. Write a text file (parent folder must exist) and open it in Notepad. file alone opens an existing file/folder. Text is inserted with textContent/value only — never parsed as HTML.
url=https://...Mở trong Trình duyệt. Chỉ http/https; tên miền trần được thêm https://, chữ khác thành tìm kiếm Wikipedia. Open in the Browser app. Only http/https; anything else is rejected or turned into a Wikipedia search. Many sites forbid iframes — use the “Mở tab mới” button.
msg=...Mở «Gợi ý trả lời» và đặt mảng JSON gợi ý vào #bot-output. Open the reply suggester; a JSON array [{tone,intent,text}] goes to #bot-output.
calc=biểu thứcTính bằng Máy tính (bộ phân tích an toàn, không eval). Evaluate with the Calculator (safe parser, no eval). + - * / % ( )
theme=dark|lightGiao diện tối/sáng. Dark/light theme.
wallpaper=bloom, sunset, ocean, forest, night, pastel
accent=xanh, tim, hong, do, cam, la
close=app|winId|allĐóng cửa sổ. Close windows.
script=[...]Mảng JSON các bước (tối đa 50), chạy tuần tự. URL-encoded JSON array of steps (max 50), run in order. Khóa hợp lệ / allowed keys: run, open, close, cmd, file, text, url, theme, wallpaper, accent, msg, calc, wait (≤10000 ms), power (sleep|shutdown|restart), maximize, minimize, focus. Khóa khác bị từ chối. Any other key is rejected.
[{"run":"calc"},{"cmd":"ls"},{"wait":500},{"msg":"chào em"},{"maximize":"reply"}]

Thứ tự xử lý / processing order: theme, wallpaper, accent → run → file/text → url → calc → msg → script → cmd → close.

Kết quả trong DOM / Results in the DOM

  • body[data-ready="1"] khi mọi bước xong; cũng có sự kiện pcao:ready. Set when all steps are done; a pcao:ready event fires too.
  • <pre id="bot-output"> – kết quả bước cuối cùng. Result of the last step. body[data-last-output-at] is updated each time.
  • <pre id="bot-log"> – JSON mọi bước [{step,ok,result|error}].
  • <pre id="bot-state"> – JSON trạng thái (cửa sổ, giao diện, cwd…). Live JSON state.
  • Cửa sổ .win có / windows carry data-app, data-win-id, data-state, data-title, data-focused, và tùy app / plus data-file, data-path, data-cwd, data-url, data-result, data-suggestions.

API JavaScript / JavaScript API (window.pcAo)

Cho Puppeteer/Playwright. For Puppeteer/Playwright via page.evaluate.

await pcAo.ready                      // kết quả các bước từ URL / results of URL steps
pcAo.version                          // "1.0.0"
pcAo.listApps()                       // [{id,name}]
pcAo.open("notepad", arg?)            // → window id
pcAo.close("notepad" | "w3" | "all")
pcAo.exec("ls /Tài liệu")             // → output string (also #bot-output)
pcAo.terminal("mkdir a;cd a;pwd")     // runs in the visible Terminal
pcAo.writeFile("/Tài liệu/a.txt", "nội dung")
pcAo.readFile("/Tài liệu/a.txt")
pcAo.ls("/"), pcAo.mkdir(p), pcAo.rm(p), pcAo.openFile(p)
pcAo.browse("https://example.com")    // http/https only
pcAo.reply("anh làm nghề gì vậy")     // → [{tone,intent,text}]
pcAo.calc("2+3*4")                    // → 14
pcAo.setTheme("light"), pcAo.setWallpaper("ocean"), pcAo.setAccent("tim"), pcAo.wallpapers()
await pcAo.run([{"run":"calc"},{"calc":"1+1"}])   // same whitelist as script=
pcAo.state()                          // JSON state
await pcAo.screenshot()               // → PNG data URL (DOM rendered via SVG foreignObject; iframes shown as placeholder)
pcAo.unlock()

Bảo mật / Security

  • Không bao giờ eval JS từ URL; chỉ chạy các hành động trong danh sách trắng. Nothing from the URL is ever eval'd; only whitelisted actions run.
  • Văn bản từ tham số chỉ được chèn bằng textContent/value. Text from params is inserted via textContent/value only.
  • Trình duyệt chỉ tải http/https. The Browser app only loads http/https URLs.
  • Dữ liệu (tệp ảo, cài đặt) chỉ nằm trong localStorage của trình duyệt bạn. Files and settings live only in your browser's localStorage. No backend, no API keys.
